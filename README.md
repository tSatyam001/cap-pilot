# CapPilot

CapPilot is a React + TypeScript application for equity/shareholding workflows.

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase

## Local Development

Requirements:

- Node.js 18+
- npm

Run locally:

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
npm run preview
```

## Environment

Create a `.env` file based on `.env.example` and provide your Supabase values before running the app.
